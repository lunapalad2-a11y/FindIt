\# FindIt – PLM Campus Lost and Found System



\## About the Project

FindIt is a web-based Campus Lost and Found System

designed for students, faculty, and staff of

Pamantasan ng Lungsod ng Maynila (PLM).



It allows users to report lost items, post found

belongings, and submit claims for items they recognize.



\## Main Features

\- User registration and login

\- Lost and found item reporting

\- Item search and filtering

\- Item management

\- Claim submission and management

\- Admin dashboard

\- User and admin roles

\- Responsive design

\- Dark mode

\- Form validation



\## Technologies Used

\- HTML5

\- CSS3

\- JavaScript

\- PHP

\- MySQL / MariaDB

\- Git and GitHub



\## Local Setup

1\. Install XAMPP.

2\. Place the project inside `htdocs/findit`.

3\. Create the `findit\_db` database.

4\. Configure your local database connection.

5\. Start Apache and MariaDB.

6\. Open `http://localhost/findit`.
