# FindIt - PLM Campus Lost and Found System

## About the Project

FindIt is a web-based Campus Lost and Found System designed for students, faculty, and staff of Pamantasan ng Lungsod ng Maynila (PLM).

It allows users to report lost items, post found belongings, search for reported items, and submit claims for items they recognize.

## Main Features

- User registration and login
- Lost and found item reporting
- Item search and filtering
- Item editing and deletion
- Claim submission and management
- Admin dashboard
- User and admin roles
- Responsive design
- Dark mode
- Form validation
- Item approval and moderation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- PHP
- MySQL / MariaDB
- Fetch API
- Git and GitHub

## Project Structure

- `admin/` - Admin dashboard and management pages
- `api/` - API endpoints
- `assets/` - CSS, JavaScript, and images
- `config/` - Local database configuration
- `uploads/` - Uploaded item photos
- `user/` - User features and pages

## Local Installation

1. Install XAMPP on your computer.
2. Clone or download this repository.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Create a database named `findit_db`.
5. Configure your local database connection in `config/database.php`.
6. Start Apache and MySQL/MariaDB using XAMPP.
7. Open `http://localhost/findit` in your browser.
8. Register an account to start using the application.

## Database Configuration

The `config/database.php` file is intentionally excluded from the repository because it contains local database connection settings.

Create your own local configuration file and use the appropriate database host, port, username, and password for your environment.
